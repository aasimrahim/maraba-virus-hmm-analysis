# Maraba Virus HMM Analysis
Hidden Markov Model (HMM) analysis of oncocell-binding protein mechanisms in the Maraba virus. Comparative viral genomics, multiple sequence alignment (MSA), HMM training, and proteome scanning to identify candidate oncogenic cell-targeting proteins.
## Key Highlights
- Built a custom Hidden Markov Model (HMM) from aligned viral protein sequences
- Applied Viterbi decoding and likelihood scoring to identify conserved oncocell-binding motifs
- Performed comparative viral genomics across vesiculoviruses (including Maraba virus)
- Validated candidate protein regions using proteome-wide HMM scanning
